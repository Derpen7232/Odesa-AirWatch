# Odesa-AirWatch 🌬️📍

**Odesa-AirWatch** — це сервіс оперативного моніторингу якості повітря в районах міста Одеса, що допомагає мешканцям приймати рішення про прогулянки, провітрювання оселі чи заняття спортом на відкритому повітрі.

## 🎯 Пітч проєкту
Мешканці Одеси часто стикаються з проблемою промислових або специфічних морських запахів, а також пилу. **Odesa-AirWatch** вирішує проблему відсутності єдиного, зрозумілого та локалізованого джерела даних про забруднення. Користувач отримує миттєвий статус повітря («Чисто», «Помірно», «Небезпечно») у своєму районі без необхідності розшифровувати складні хімічні показники.

## 📉 Проблема
Відсутність швидкого доступу до агрегованих даних про стан повітря в конкретних точках міста (Приморський, Київський, Пересипський райони тощо), що створює ризики для здоров'я чутливих груп населення.

## 📍 Мета першої ітерації
Створити MVP-версію веб-інтерфейсу або бота, що відображає індекс якості повітря (AQI) на основі відкритих даних (наприклад, SaveEcoBot або PurpleAir) для 3-х ключових точок Одеси.

## 👥 Карта стейкхолдерів
* **Користувачі (User):** Жителі міста, батьки маленьких дітей, спортсмени, люди з алергіями.
* **Власник продукту (Student/Product Lead):** Визначає пріоритети фіч та джерела даних.
* **Джерела даних (Data Providers):** Муніципальні датчики, громадські мережі моніторингу (API).
* **Експерти:** Екологи (для верифікації критеріїв "небезпечного" рівня).

## ✅ Definition of Success (Ознаки успіху)
1. Користувач може за 2 кліки дізнатися стан повітря у своєму районі.
2. Дані оновлюються не рідше ніж раз на годину.
3. Система коректно відображає статус навіть при низькій швидкості мобільного інтернету.
