#  Odesa-AirWatch: Tactical Radar Pro

**Odesa-AirWatch** — це OSINT-платформа для моніторингу повітряної обстановки в реальному часі. Проєкт агрегує дані з відкритих джерел для візуалізації руху ворожих БпЛА та балістичних загроз, надаючи користувачам тактичну картину неба над Одещиною.

---

##  Основні модулі (Military Features)

На основі реалізованого коду:
* **Ballistic Tracking Engine:** Алгоритми прогнозування траєкторії балістичних цілей (`isBallisticMode`).
* **Shahed Launch Tracker:** Система моніторингу запусків з окупованих територій (Кримський вектор).
* **Dynamic Danger Zones:** Візуалізація радіуса загрози на основі типу цілі.
* **Air Raid Alert System:** Автоматичне сповіщення про зміну статусу небезпеки з таймером тривалості загрози.
* **AD Position Masking:** Координати цілей відображаються з розрахунковим розкидом для безпеки позицій ППО.

---

##  План MVP
**Мета:** Створити надійну систему візуалізації повітряних загроз з мінімальною затримкою даних.

### Користувацький сценарій:
1. Користувач заходить у систему, проходить ініціалізацію CRT-інтерфейсу.
2. Система підключається до сокетів та отримує координати активних цілей.
3. При виявленні "Шахедів" радар будує вектор руху в напрямку Одеси.
4. При загрозі балістики HUD переходить у режим критичної тривоги (`--danger`).

---

##  Ознаки успіху (Definition of Success)
1. **Точність візуалізації:** Плавне переміщення цілей при `REFRESH_RATE_MS = 16`.
2. **Інформативність:** Користувач може ідентифікувати тип загрози за візуальним маркером протягом 2 секунд.
3. **Стабільність:** Коректне відновлення сесії через `localStorage` при випадковому перезавантаженні сторінки.
