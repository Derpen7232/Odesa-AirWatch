#  Odesa-AirWatch: Radar System Pro

**Odesa-AirWatch** — це інтерактивна платформа для моніторингу та візуалізації стану атмосферного повітря в Одеському регіоні. Проєкт використовує стилістику "тактичного радара" для оперативного відображення зон забруднення, поширення часток або інших екологічних загроз у реальному часі.

---

##  Про проєкт (Pitch)
В умовах промислового портового міста мешканці Одеси потребують швидкого та зрозумілого інструменту для оцінки якості повітря. **Odesa-AirWatch** перетворює складні дані на динамічну карту-радар. Це дозволяє користувачеві за лічені секунди оцінити екологічну ситуацію, використовуючи інтуїтивно зрозумілий інженерний інтерфейс.

---

##  Технічні особливості (Features)

Проєкт уже містить наступний функціонал, реалізований на рівні коду:
* **Radar Engine:** Система відстеження об'єктів (хмар забруднення) у реальному часі з плавним оновленням координат (~60 FPS).
* **Dynamic Mapping:** Повна інтеграція з мапами `Leaflet.js`, автоматичне центрування на Одесі (`START_CENTER_POINT`).
* **Cyberpunk HUD:** Високотехнологічний інтерфейс із CRT-ефектами, сканлайнами та анімованими глітч-ефектами для заголовків.
* **Alert System:** Віджет "Air Raid Status", адаптований під екологічні сповіщення про критичні рівні небезпеки.
* **User Sessions:** Система ідентифікації користувачів та ролей (`admin`/`user`) для доступу до розширеної аналітики.

##  План MVP (Minimum Viable Product)

**Ядро цінності:** Візуалізація зон забруднення на мапі міста з миттєвим сповіщенням про небезпеку.

### Основний сценарій користувача:
1.  Користувач відкриває `радар.html`.
2.  Система ініціалізує HUD-інтерфейс та підвантажує актуальну мапу.
3.  На екрані з'являються маркери активних зон (цілі).
4.  При вході зони забруднення в житловий сектор, статус-віджет змінюється на "КРИТИЧНИЙ СТАН".

---

##  Definition of Success (Ознаки успіху)

* **Продуктивність:** Рендеринг інтерфейсу без затримок завдяки оптимізованому циклу `REFRESH_RATE_MS = 16`.
* **Візуальна чіткість:** Коректне відображення глітч-ефектів та CRT-фільтрів у сучасних браузерах.
* **Стабільність:** Автоматичне збереження сесії користувача в `localStorage`.
