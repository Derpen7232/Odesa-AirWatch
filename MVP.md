#  Minimum Viable Product (MVP) — Odesa-AirWatch

Цей документ описує мінімальний набір функцій, необхідних для запуску системи моніторингу повітря в стилі радара.

###  Основна цінність (Core Value)
Надання мешканцям Одеси візуальної інформації про екологічні загрози через інтерактивний футуристичний інтерфейс, що спрощує сприйняття складних даних.

###  Ключовий функціонал MVP
1. **Interactive Radar Map:** Використання бібліотеки Leaflet для відображення території Одеси з накладеними шарами моніторингу.
2. **Target Tracking:** Візуалізація зон забруднення як "цілей" на радарі (використання об'єктів `targets` у `script.js`).
3. **Cyberpunk HUD:** Робоча панель керування з CRT-ефектами для відображення поточного статусу системи.
4. **Air Raid Status:** Модуль термінового сповіщення про зміну якості повітря до критичного рівня.
5. **Local Session:** Збереження налаштувань користувача та його ролі через `localStorage`.

###  Користувацький сценарій (User Journey)
1. **Запуск:** Користувач відкриває `радар.html`, бачить анімацію завантаження та CRT-оверлей.
2. **Огляд:** Система автоматично фокусується на Одесі (`START_CENTER_POINT`).
3. **Моніторинг:** Користувач спостерігає за рухом маркерів забруднення на мапі.
4. **Взаємодія:** При кліку на "ціль" відкривається картка з детальною інформацією про тип забруднення.
5. **Сповіщення:** Якщо активується режим тривоги, HUD змінює колір на `var(--danger)` (червоний), сигналізуючи про небезпеку.

###  Технічні обмеження
- Дані про забруднення на етапі MVP можуть транслюватися з певною затримкою або розкидом для тестування стабільності інтерфейсу.
